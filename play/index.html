Finding your files

Where is my Data Files folder?

Morrowind keeps everything the game needs in one folder called Data Files. It holds Morrowind.esm and the Music, Sound and Video folders. You are looking for that folder, not the game's shortcut and not the installer.

Steam

In Steam, right-click The Elder Scrolls III: Morrowind in your Library and choose Manage › Browse local files. A window opens on the game folder; Data Files is inside it. If you would rather navigate by hand, the usual location is:

  • Windows
    C:\Program Files (x86)\Steam\steamapps\common\Morrowind\Data Files
  • macOS
    ~/Library/Application Support/Steam/steamapps/common/Morrowind/Data Files
  • Linux
    ~/.steam/steam/steamapps/common/Morrowind/Data Files

Installed to a second drive or a custom Steam library? Use Browse local files rather than guessing the path, since Steam puts extra libraries wherever you chose (often D:\SteamLibrary\steamapps\common\Morrowind).

GOG.com

In GOG Galaxy, open Morrowind, click the gear beside Play and choose Manage installation › Show folder. Without Galaxy, it is wherever the offline installer put it. The usual location is:

  • Windows
    C:\GOG Games\Morrowind\Data Files
    older installs: C:\Program Files (x86)\GOG.com\Morrowind\Data Files
  • macOS
    The GOG release ships as an app bundle. Right-click Morrowind.app in Applications, choose Show Package Contents, then look in Contents/Resources/game/Data Files.
  • Linux
    ~/GOG Games/Morrowind/game/Data Files

How to tell you have the right folder

It contains Morrowind.esm. If you own the expansions it also has Tribunal.esm and Bloodmoon.esm, plus folders named Music, Sound and Video. If you see Morrowind.exe but no .esm files, you are one level too high: open Data Files inside it.

Nothing leaves your machine except the files listed on the previous screen, and they go only to your own account's private locker.

Add your Morrowind files

Your game data lives in your account, so it follows you to any device. Choose your Morrowind Data Files folder once and we find everything below inside it, including music, videos and voices. It uploads to your private locker and is verified. You only do this the first time.
